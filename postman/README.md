# 📮 Colección de Postman - Autolote API Tests

## 📥 Cómo importar la colección

### Opción 1: Importar archivo (Recomendado)

1. **Descargar los archivos:**
   - `Autolote API Tests.postman_collection.json`
   - `Autolote.postman_environment.json`

2. **Abrir Postman**

3. **Importar la colección:**
   - Haz clic en **"Import"** (botón en la esquina superior izquierda)
   - Arrastra el archivo `Autolote API Tests.postman_collection.json`
   - O haz clic en **"Upload Files"** y selecciona el archivo

4. **Importar el Environment:**
   - Repite el proceso con `Autolote.postman_environment.json`

5. **Seleccionar el Environment:**
   - En la esquina superior derecha, selecciona **"Autolote"** en el dropdown
